手动构建步骤：
# 1. 进入项目目录
cd F:\1.SongWeitian\1.project\iec104_parser
# 2. 清理旧构建
rmdir /s /q dist build
# 3. 执行构建
python -m PyInstaller --name="IEC104_Parser" --onedir --windowed --icon=NONE --add-data=".;." --noconfirm --clean main.py
# 4. 输出位置
dist\IEC104_Parser\IEC104_Parser.exe
或者直接双击 build.bat（但需要确保 Python 在系统 PATH 中）。
