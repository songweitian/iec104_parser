# IEC60870-5-104 报文解析器

基于 IEC 60870-5-104 (2002版) 协议的报文解析软件，支持主站/子站双向报文解析，提供直观的图形化界面。

## 功能特性

### 核心解析功能
- **APCI 帧解析**：支持 I-format（信息传输）、S-format（编号监视）、U-format（未编号控制）三种帧类型
- **ASDU 解析**：类型标识、可变结构限定词、传送原因、公共地址、信息对象地址、时标等
- **主站/子站角色识别**：根据报文的类型标识自动判定发送方向和角色
- **多种数据类型**：单点/双点信息、测量值（归一化/标度化/短浮点）、累计量、命令等
- **CP56Time2a / CP24Time2a 时标解析**：精确到毫秒级

### 智能输入处理
- **自动检测模式**：自动识别普通十六进制、XN3000（RX/TX格式）、XN8000（send/recv格式）
- **多种输入格式**：支持空格分隔、点分隔、0x前缀、换行合并
- **通信日志格式**：支持带时间戳和方向标记的日志文件
- **文件导入**：支持 .txt / .log / .hex / .bin / .pcap 格式
- **拖拽导入**：直接拖放文件到窗口

### 多标签页输入
- 支持同时打开多个输入标签页
- 标签页可关闭，Ctrl+N 新建

### 解析结果展示
- **解析详情树**：树形结构展示各字段，点击字段高亮原始字节
- **报文列表**：颜色编码的表格概览，按帧类型着色
- **原始十六进制**：格式化后的原始数据，支持字段级高亮
- **时间间隔分析**：显示帧间时间间隔，颜色标记异常间隔
- **序列号可视化**：检测并标记序列号跳跃

### 过滤与搜索
- **多维过滤**：按信号类型、类型标识、传送原因、公共地址、IOA范围过滤
- **正则搜索**：搜索框支持正则表达式
- **列显示控制**：右键表头可隐藏/显示指定列

### 书签与定位
- **书签标记**：按 Space 标记重要帧，Ctrl+Up/Down 跳转
- **报文定位**：F2 或右键菜单定位到原始报文位置并高亮
- **键盘导航**：Enter 显示详情、F2 定位、Space 切换书签

### 导出功能
- **CSV**：Excel兼容，含UTF-8 BOM
- **JSON**：结构化数据，便于程序处理
- **TXT**：人类可读的文本报告
- **筛选导出**：只导出过滤后的可见行

### 分析工具
- **统计图表**：信号类型饼图、帧类型柱状图、COT分布、方向分布
- **协议合规检查**：APDU长度、帧长度、VSQ匹配、品质描述词等
- **序列号检查**：检测I帧序列号连续性
- **报文配对分析**：分析主站命令与子站响应
- **报文对比**：并排对比两组报文的差异

### 工具功能
- **帧生成器**：根据参数生成符合标准的IEC104报文帧
- **IOA地址别名**：管理IOA地址与名称的映射关系
- **历史会话管理**：保存/加载/删除解析会话

### 界面功能
- **深色/浅色主题**：Ctrl+Shift+D 切换
- **折叠/展开输入面板**：Ctrl+B
- **关于页面**：版本信息和IOA地址说明

### 注册激活
- **硬件绑定**：激活码与机器硬件指纹绑定
- **未激活限制**：仅支持单条报文解析
- **已激活功能**：解锁全部功能

## 运行环境

- Python 3.8+
- PyQt5 >= 5.15.0

## 快速开始

### 方法一：直接运行 Python 源码

```bash
# 安装依赖
pip install PyQt5

# 运行程序
python main.py
```

### 方法二：打包为 exe

```bash
# 安装打包工具
pip install pyinstaller

# 运行构建脚本
build.bat

# 或手动打包
python -m PyInstaller --onedir --windowed --name="IEC104_Parser" main.py

# 可执行文件在 dist/IEC104_Parser/ 目录下
```

## 使用说明

### 输入报文格式

**格式一：普通十六进制**
```
68 04 01 00 0E 00
68 0E 04 00 14 00 09 01 03 00 01 00 01 40 00 46 02 00
```

**格式二：通信日志格式**
```
13:25:00.692 RX:
68 15 15 16 0A 00 0B 01 03 00 01 00 0A 40 00 28 04 00 00 00 00 00 00
13:25:00.693 TX:
68 04 01 00 16 17
```

**格式三：点分隔格式（XN3000）**
```
68.15.15.16.0a.00
```

### 解析步骤

1. 粘贴报文数据到输入框（或拖放文件）
2. 点击 **▶ 解析报文** 按钮（或按 F5）
3. 在右侧查看解析结果

### 导出结果

点击工具栏的 CSV/JSON/TXT 按钮，或使用菜单 文件 → 导出。

### 激活软件

1. 帮助 → 软件激活
2. 复制硬件指纹发送给开发者
3. 输入激活码完成激活

## 支持的协议类型

### 监视方向（子站→主站）

| 类型ID | 名称 | 说明 |
|--------|------|------|
| 1 | M_SP_NA_1 | 单点信息 |
| 3 | M_DP_NA_1 | 双点信息 |
| 5 | M_ST_NA_1 | 步位置信息 |
| 7 | M_BO_NA_1 | 32比特串 |
| 9 | M_ME_NA_1 | 测量值(归一化) |
| 11 | M_ME_NB_1 | 测量值(标度化) |
| 13 | M_ME_NC_1 | 测量值(短浮点) |
| 15 | M_IT_NA_1 | 累计量 |
| 30 | M_SP_TB_1 | 单点信息(CP56Time2a) |
| 31 | M_DP_TB_1 | 双点信息(CP56Time2a) |
| 34 | M_ME_TD_1 | 测量值归一化(CP56Time2a) |
| 35 | M_ME_TE_1 | 测量值标度化(CP56Time2a) |
| 36 | M_ME_TF_1 | 测量值短浮点(CP56Time2a) |
| 70 | M_EI_NA_1 | 初始化结束 |

### 控制方向（主站→子站）

| 类型ID | 名称 | 说明 |
|--------|------|------|
| 45 | C_SC_NA_1 | 单点命令 |
| 46 | C_DC_NA_1 | 双点命令 |
| 100 | C_IC_NA_1 | 总召唤命令 |
| 103 | C_CS_NA_1 | 时钟同步命令 |
| 108 | P_ME_NA_1 | 参数(归一化值) |
| 120-127 | F_* | 文件传输命令 |

## IOA 地址分段

| IOA 范围 | 信号类型 | 说明 |
|----------|----------|------|
| 0x0001 ~ 0x4000 | 遥信 (YX) | 单点/双点信息 |
| 0x4001 ~ 0x5000 | 遥测 (YC) | 测量值 |
| 0x6001 ~ 0x6100 | 遥控 (YK) | 控制命令 |
| 0x6201 ~ 0x6400 | 遥调 (YT) | 调节命令 |
| 0x6401 ~ 0x6600 | 遥脉 (YM) | 电度/累计量 |
