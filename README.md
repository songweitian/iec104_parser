# IEC60870-5-104 报文解析器

基于 IEC 60870-5-104 (2002版) 协议的报文解析软件，支持主站/子站双向报文解析，提供直观的图形化界面。

## 功能特性

- **APCI 帧解析**：支持 I-format（信息传输）、S-format（编号监视）、U-format（未编号控制）三种帧类型
- **ASDU 解析**：类型标识、可变结构限定词、传送原因、公共地址、信息对象地址、时标等
- **主站/子站角色识别**：根据报文的类型标识自动判定发送方向和角色
- **多种数据类型**：单点/双点信息、测量值（归一化/标度化/短浮点）、累计量、命令等
- **CP56Time2a 时标解析**：精确到毫秒级
- **文件导入**：支持 .txt / .log / .hex / .bin 格式的报文文件
- **多格式导出**：CSV（Excel兼容）、JSON、TXT
- **过滤筛选**：按类型标识、传送原因、公共地址进行过滤
- **解析统计**：有效/无效报文计数、I/S/U帧分类、主从站方向统计
- **关于页面**：显示版本、编辑日期和作者信息

## 运行环境

- Python 3.8+
- PyQt5 >= 5.15.0

## 快速开始

### 方法一：直接运行 Python 源码

```bash
# 安装依赖
pip install PyQt5

# 运行程序
python main.py
```

### 方法二：打包为 exe

```bash
# 安装打包工具
pip install pyinstaller

# 运行构建脚本
build.bat

# 或手动打包
python -m PyInstaller --onefile --windowed --name="IEC104_Parser" main.py

# 可执行文件在 dist/ 目录下
```

## 使用说明

### 输入报文格式

在左侧输入框中粘贴十六进制报文，支持以下格式：

```
68 04 01 00 0E 00
68 0E 04 00 14 00 09 01 03 00 01 00 01 40 00 46 02 00
680E04001400090103000100014000460200
```

- 支持空格分隔或不带空格的十六进制字符串
- 每行一条报文
- 以 `#` 开头的行为注释

### 解析步骤

1. 粘贴报文数据到输入框
2. 点击 **▶ 解析报文** 按钮（或按 F5）
3. 在右侧查看解析结果：
   - **解析详情** 标签页：树形结构展示各字段
   - **报文列表** 标签页：表格形式概览所有报文
   - **原始十六进制** 标签页：查看格式化后的原始数据

### 导出结果

解析结果可导出为：
- **CSV**：Excel兼容，含UTF-8 BOM
- **JSON**：结构化数据，便于程序处理
- **TXT**：人类可读的文本报告

## 支持的协议类型

### 监视方向（子站→主站）

| 类型ID | 名称 | 说明 |
|--------|------|------|
| 1 | M_SP_NA_1 | 单点信息 |
| 3 | M_DP_NA_1 | 双点信息 |
| 9 | M_ME_NA_1 | 测量值(归一化) |
| 11 | M_ME_NB_1 | 测量值(标度化) |
| 13 | M_ME_NC_1 | 测量值(短浮点) |
| 15 | M_IT_NA_1 | 累计量 |
| 30 | M_SP_TB_1 | 单点信息(CP56Time2a) |
| 31 | M_DP_TB_1 | 双点信息(CP56Time2a) |
| 34 | M_ME_TD_1 | 测量值归一化(CP56Time2a) |
| 35 | M_ME_TE_1 | 测量值标度化(CP56Time2a) |
| 36 | M_ME_TF_1 | 测量值短浮点(CP56Time2a) |
| 70 | M_EI_NA_1 | 初始化结束 |

### 控制方向（主站→子站）

| 类型ID | 名称 | 说明 |
|--------|------|------|
| 45 | C_SC_NA_1 | 单点命令 |
| 46 | C_DC_NA_1 | 双点命令 |
| 100 | C_IC_NA_1 | 总召唤命令 |
| 103 | C_CS_NA_1 | 时钟同步命令 |

更多类型详见标准文档。
