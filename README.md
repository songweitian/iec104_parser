# IEC60870-5-104 报文解析器

基于 IEC 60870-5-104 (2002版) 协议的报文解析软件，支持主站/子站双向报文解析，提供直观的图形化界面。

## 功能特性

### 核心解析功能
- **APCI 帧解析**：支持 I-format（信息传输）、S-format（编号监视）、U-format（未编号控制）三种帧类型
- **ASDU 解析**：类型标识、可变结构限定词、传送原因、公共地址、信息对象地址、时标等
- **主站/子站角色识别**：根据报文的类型标识自动判定发送方向和角色
- **多种数据类型**：单点/双点信息、测量值（归一化/标度化/短浮点）、累计量、命令等
- **CP56Time2a / CP24Time2a 时标解析**：精确到毫秒级

### 智能输入处理
- **自动检测模式**：自动识别普通十六进制、XN3000（RX/TX格式）、XN8000（send/recv格式）
- **多种输入格式**：支持空格分隔、点分隔、0x前缀、换行合并
- **通信日志格式**：支持带时间戳和方向标记的日志文件
- **文件导入**：支持 .txt / .log / .hex / .bin / .pcap 格式
- **拖拽导入**：直接拖放文件到窗口

### 多标签页输入
- 支持同时打开多个输入标签页
- 标签页可关闭，Ctrl+N 新建

### 解析结果展示
- **解析详情树**：树形结构展示各字段，点击字段高亮原始字节
- **报文列表**：颜色编码的表格概览，按帧类型着色
- **原始十六进制**：格式化后的原始数据，支持字段级高亮
- **时间间隔分析**：显示帧间时间间隔，颜色标记异常间隔
- **序列号可视化**：检测并标记序列号跳跃

### 过滤与搜索
- **多维过滤**：按信号类型、类型标识、传送原因、公共地址、IOA范围过滤
- **正则搜索**：搜索框支持正则表达式
- **列显示控制**：右键表头可隐藏/显示指定列

### 书签与定位
- **书签标记**：按 Space 标记重要帧，Ctrl+Up/Down 跳转
- **报文定位**：F2 或右键菜单定位到原始报文位置并高亮
- **键盘导航**：Enter 显示详情、F2 定位、Space 切换书签

### 导出功能
- **CSV**：Excel兼容，含UTF-8 BOM
- **JSON**：结构化数据，便于程序处理
- **TXT**：人类可读的文本报告
- **筛选导出**：只导出过滤后的可见行

### 分析工具
- **统计图表**：信号类型饼图、帧类型柱状图、COT分布、方向分布
- **协议合规检查**：APDU长度、帧长度、VSQ匹配、品质描述词等
- **序列号检查**：检测I帧序列号连续性
- **报文配对分析**：分析主站命令与子站响应
- **报文对比**：并排对比两组报文的差异

### 工具功能
- **帧生成器**：根据参数生成符合标准的IEC104报文帧，遥控/遥调支持选择（预制）/执行
- **通信模拟器**：主站/从站模式 TCP 通信模拟，四遥数据表格化展示，从站模式下可编辑点位值
- **IOA地址别名**：管理IOA地址与名称的映射关系
- **历史会话管理**：保存/加载/删除解析会话

### 界面功能
- **深色/浅色主题**：Ctrl+Shift+D 切换
- **折叠/展开输入面板**：Ctrl+B
- **关于页面**：版本信息和IOA地址说明

### 注册激活
- **硬件绑定**：激活码与机器硬件指纹绑定
- **非对称签名防伪**：激活码由开发者私钥以 Ed25519 签名，客户端仅内置公钥验签——用户无法伪造或篡改激活码
- **永久/限时授权**：限时授权按到期日期锁定（查看下方"激活码生成"新格式）
- **未激活可用**：粘贴/编辑报文、单条解析（每次仅解析第 1 条）、搜索、书签、筛选
- **未激活受限**：多条批量解析、文件导入（含拖放）、导出 CSV/JSON/TXT、帧生成器、报文对比、通信模拟器、历史会话管理、多标签页输入
- **已激活**：解锁全部功能

## 运行环境

- Python 3.8+
- PyQt5 >= 5.15.0
- cryptography >= 42（Ed25519 验签）

## 快速开始

### 方法一：直接运行 Python 源码

```bash
# 安装依赖
pip install PyQt5

# 运行程序
python main.py
```

### 方法二：打包为 exe

```bash
# 安装打包工具
pip install pyinstaller

# 运行构建脚本（推荐，参数与下方手动命令一致）
build.bat

# 或手动打包
python -m PyInstaller --onedir --windowed --name="IEC104_Parser" ^
    --icon=assets/app.ico ^
    --exclude-module gen_license ^
    main.py

# 可执行文件在 dist/IEC104_Parser/ 目录下，
# license.dat 需与 IEC104_Parser.exe 同目录
```

> ⚠ 打包注意：不要使用 `--add-data` 将源码目录打进发行包——
> 那会把 `gen_license.py`（激活码签发工具，含签名密钥）等源码泄露给使用者。

## 使用说明

### 输入报文格式

**格式一：普通十六进制**
```
68 04 01 00 0E 00
68 0E 04 00 14 00 09 01 03 00 01 00 01 40 00 46 02 00
```

**格式二：通信日志格式**
```
13:25:00.692 RX:
68 15 15 16 0A 00 0B 01 03 00 01 00 0A 40 00 28 04 00 00 00 00 00 00
13:25:00.693 TX:
68 04 01 00 16 17
```

**格式三：点分隔格式（XN3000）**
```
68.15.15.16.0a.00
```

### 解析步骤

1. 粘贴报文数据到输入框（或拖放文件）
2. 点击 **▶ 解析报文** 按钮（或按 F5）
3. 在右侧查看解析结果

### 导出结果

点击工具栏的 CSV/JSON/TXT 按钮，或使用菜单 文件 → 导出。

### 激活软件

1. 帮助 → 软件激活
2. 复制硬件指纹发送给开发者
3. 输入激活码完成激活

- **授权形式**：支持永久授权与限时授权（按到期日期，如 `2026-12-31`），激活码内嵌到期日期并由 **Ed25519 非对称签名** 防伪（客户端只内置公钥、无法伪造激活码），到期日当天仍可使用。
- **到期行为**：授权到期后，受限功能被锁定（降为未激活状态），启动时弹出"授权已到期"提示，在 帮助 → 软件激活 中输入新的激活码即可恢复全部功能。
- **激活对话框**：已激活时显示"永久授权"或"有效期至…，剩余 N 天"；到期后显示"已过期"，可直接重新输入激活码。

## 激活码生成

开发者使用 `gen_license.py` 为用户生成激活码（需 `cryptography` 依赖）：

```bash
# 首次使用：生成密钥对（私钥保存到本机 license_ed25519.key，仅开发者持有）
python gen_license.py --gen-keys

# 查看客户端需内置的公钥常量（如重新生成密钥，须同步 license.py 的
# _LICENSE_PUBLIC_KEY_HEX 并一并发布）
python gen_license.py --public-key

# 永久授权（不带日期参数）
python gen_license.py <硬件指纹>
# 例如: python gen_license.py ABA8BCA152697B6EB01A8F31C055FB90

# 限时授权（第二个参数为到期日期 YYYY-MM-DD）
python gen_license.py <硬件指纹> 2026-12-31
```

激活码采用 **Ed25519 非对称签名**：私钥仅在开发者本地（`license_ed25519.key`，
已列入 .gitignore），客户端只内置公钥。用户无法篡改日期后缀、也无法伪造激活码；
旧版（HMAC）激活码已停用，输入旧码会提示联系开发者换发新版。
到期判定以用户本机系统时间为准，到期日当天仍可使用，次日起锁定受限功能。
